# Welcome

Hello! I'm Jake. I'm passionate about astronomy, hiking and science. Here you'll find my scientific endeavors and anything else I find interesting or want to document for myself!

My love for astronomy began when I grew up in one of the darkest places in the world, rural Australia.
I started with a small star tracker and a DSLR camera, and over the years, I've upgraded to a telescope,dedicated astro cameraand high end astrophotography mount.

When I'm not stargazing, you can often find me hiking the UK mountains!

## Commands

* `mkdocs new [dir-name]` - Create a new project.
* `mkdocs serve` - Start the live-reloading docs server.
* `mkdocs build` - Build the documentation site.
* `mkdocs -h` - Print help message and exit.
